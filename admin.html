Site settings

Site name, tagline and contact email shown across the whole site.

Header code

This code is inserted into the <head> of every page — paste AdSense / ad network code, Google Analytics, verification meta tags or custom CSS here. Footer code goes just before </body>.

Articles / Guides

Publish new guides, edit or unpublish existing ones. Content can be HTML.

Tools

Switch tools on or off and edit the name and description shown on the site. (The tool pages themselves keep working either way — turning one off only removes it from the listings.)

Admin account

Change the admin login email and password. You will need your current password.

Honest note: this is a static GitHub Pages site, so the login screen is a lock on the admin page, not server security. The real protection is your GitHub account and token — only someone with your GitHub token can actually publish changes to the site files.

GitHub Publish

Connect your GitHub repository so Publish buttons save changes into the repo — GitHub Pages then updates the live site automatically within a minute or two. Your token is stored only in this browser, never in the site files.

Backup

Download the current site data as JSON files, or restore from a backup.
